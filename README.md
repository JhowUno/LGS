# LGS
Lan Game Share

Compartilhe tela com seus amigos por meio de VPN, testado sobre o Radmin VPN para compartilhamento de jogos.
Esta versão não possui chamada de voz. Esta primeira versão veio para complementar o Discord, para aqueles que utilizavam a função de compartilhamento de tela para jogar com seus amigos. Assista até 6 transmissões simultaneamente.
Considerando o bloqueio de transmissões do Discord e o propósito deste aplicativo ele não permite o compartilhamento direto do aplicativo da câmera, imagem direta da webcam ou Obs Studio.
